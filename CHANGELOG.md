# Changelog

## 1.1.0 — Adaptive Crafting (Stable)
- Added conditional crafting recipes for all three bulbs and all three fixtures.
- Supports four installed-mod combinations: both Immersive Engineering and Ender IO, either one alone, or neither.
- Replaced the IE incandescent recipe's wire coil with a single copper wire.
- Updated LED ingredients: IE Electronic Component in IE configurations, Ender IO Zombie Electrode in Ender IO-only configuration.
- Preserved original vanilla recipes when neither technology mod is installed.
- Prepared publication documentation and source packaging.

## 1.0.9 — Localization
- Added Spanish and Russian translations, including fixture GUI labels.

## 1.0.8 — Wall Sconce and Compatibility
- Added the Wall-Mounted Sconce and realistic exposed bulb models.
- Added Ender IO redstone conduit connection compatibility.
- Removed the retired legacy Lamp Base block and item registrations.

Earlier development releases introduced the Industrial Cage Fixture, Square Flush-Mount Ceiling Light, bulb lifespans, FE buffering, and Immersive Engineering LV wiring.
